# Referências — trial-vertice

> Honestidade de método antes de qualquer decisão: nesta sessão não há ferramenta de screenshot/navegação visual real disponível para o Molda. Já foi tentado buscar sites específicos dentro das 3 galerias indicadas pelo Lucas (Awwwards, land-book.com, minimal.gallery) via leitura de texto, e o resultado não é confiável — texto não avalia cor, tipografia ou sensação visual de um site de fato. **Por isso, nenhum nome de site individual é citado abaixo como "referência analisada".** Isso seria fabricar uma referência que ninguém olhou de verdade, contra a regra de veracidade do Web OS.

O que existe em vez disso: as 3 galerias tratadas como **direção estética por reputação/características conhecidas**, combinadas com os tokens de marca já fechados em `branding/neovertix/01-estrategia.md` §8. Essa combinação é a direção visual deste projeto.

## As 3 galerias — o que cada uma empresta (não o que foi "visto" nelas)

| Galeria | Papel nesta decisão |
|---|---|
| **Awwwards** | Padrão de **qualidade de execução** (craft premiado, interação e motion intencional) — não padrão de estilo específico. Awwwards tende ao experimental/chamativo; este projeto pega só o nível de polimento técnico, não a intensidade visual. |
| **land-book.com** | Padrão de **estrutura de página B2B** — tipografia forte como elemento de hierarquia, bastante espaço, páginas de SaaS/startup modernas que convertem. Este projeto usa a lógica estrutural (hierarquia clara, espaço generoso), não o acabamento "SaaS genérico" que o land-book também cataloga em excesso (ver piso de craft em `specs/design.md`). |
| **minimal.gallery** | Padrão de **contenção visual** — restrição, espaço negativo, tipografia como protagonista, paleta contida. Este é o contrapeso direto ao hype visual que o ICP (comércio local, não startup) rejeitaria. |

## Síntese de referência (a direção real do projeto)

**Craft de Awwwards + estrutura de land-book + contenção de minimal.gallery, dentro da paleta sóbria da marca Neovertix** (`01-estrategia.md` §8):

- Off-black / off-white, nunca preto puro.
- Uma cor de destaque por tela — nunca duas disputando atenção.
- Zero gradiente azul-roxo.
- Tipografia carrega mais peso hierárquico do que a cor.
- Zero ícone de robô.

Essa síntese é a fonte de verdade das decisões de token em `specs/design.md` — não há screenshot anexado porque não há screenshot analisado. Se o Lucas tiver 1-3 links/prints específicos que queira usar como ponto de partida real (dentro do limite de 3, Dribbble/Awwwards/Pinterest), este arquivo é substituído por essa referência concreta antes do módulo 22.
